# PixelExpress Studio 🎨

A high-performance, offline-ready image editing web application built entirely using natural language prompts in Google AI Studio.

## Features
- ✂️ **Crop & Aspect Ratio:** Interactive grid with standard presets (1:1, 16:9, 4:3, etc.).
- 📐 **Precision Resizing:** Direct pixel scaling and ratio lock.
- 🔄 **Transform Tools:** 90° rotation and horizontal/vertical flipping.
- 💾 **Format & Compression:** Export to JPEG, PNG, or WebP with real-time file size estimation.

## Built With
- **Platform:** Google AI Studio (Build Mode)
- **AI Model:** Gemini Pro / Flash
- **Tech Stack:** HTML5, CSS3, JavaScript (Vanilla Canvas API)
